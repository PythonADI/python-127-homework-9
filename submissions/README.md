# Submissions

One folder per student, named after your GitHub username. Each folder
is a whole Django project:

```
submissions/
  nino-b/
    manage.py
    pyproject.toml
    uv.lock
    my_site/
    pages/
    templates/
  giorgi-k/
    manage.py
    ...
```

Only touch your own folder. See [../SUBMITTING.md](../SUBMITTING.md)
for the full walkthrough.
